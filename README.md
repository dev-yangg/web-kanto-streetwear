# Kanto

> 🚧 **Work in progress.** This repo is under active development. Things are incomplete, unstyled, or broken, and they will change without notice.

> ⚠️ **This is a concept project, not a real brand.** Kanto is a fictional streetwear brand and editorial site made for learning and portfolio practice. There is no store, no real products, no checkout, and nothing here is for sale.

## What is this?

A concept streetwear brand and editorial site inspired by Japan's Kanto region. The name works two ways:

- **Kanto (関東):** the region of Japan that includes Tokyo, the visual reference for the brand.
- **Kanto (Filipino):** a street corner, the local, everyday-street side of the brand.

The design aims to show both meanings at once.

## Why I'm building it

I'm using this project to relearn **Gatsby 5** properly, including its GraphQL data layer, TypeScript, and MDX-based content. It's a practice build, not a client project.

## Tech stack

- [Gatsby 5](https://www.gatsbyjs.com/) + React
- TypeScript
- GraphQL
- MDX for editorial content
- Tailwind CSS v4 (migrating from the v3 the Gatsby CLI scaffolded)
- Netlify for hosting
